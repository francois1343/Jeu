Défauts prioritaires

ARCHITECTURE

React ou Vue maintenant ?

NON, PAS ENCORE

Une migration complète aujourd’hui déplacerait les bugs au lieu de les résoudre. Le catalogue contient beaucoup de jeux autonomes qui fonctionnent bien en JavaScript natif.

  1. Maintenant : stabiliser le shell, les modales et les composants communs.
  2. Ensuite : isoler accueil, admin et matchmaking en modules.
  3. Plus tard : choisir React/Vue uniquement si ces écrans deviennent difficiles à maintenir sans framework.

Recommandation : Web Components ou petits modules ES pour le socle partagé ; conserver les moteurs de jeux indépendants.
